Report a bug

  1. In the app, choose Help ▸ Report a Bug….
  2. Say what happened and how to make it happen again.
  3. Read the report below the form. It is everything that would be shared, nothing else.
  4. Click Copy and Open GitHub Issue and paste the report into the new issue (see Contact), or Copy / Save as File… to keep it.

After a crash, the next launch offers the crash report: click Report… to add it to a bug report.

What a report contains

  • The app version, the system version and the computer model.
  • The style and theme you use (macOS, Windows 11 or Linux, light or dark).
  • If you leave it ticked: the last lines of the app's own log. If you add it: the crash report.
  • Your home folder is shown as ~. File and folder names are replaced with [path] unless you tick Include file and folder names.

Better Explora never uploads anything by itself. See Privacy.

Contact

GitHub Issues: bugs

Open a new issue and paste the report from Help ▸ Report a Bug… (its Copy and Open GitHub Issue button copies it and opens this page). Issues are public: read the report first and remove anything you don't want to share. You need a free GitHub account.

See the open issues: your problem may already be known.

Discord: questions and help

Ask how to do something, share tips and talk with other users. The invite link is coming soon.
